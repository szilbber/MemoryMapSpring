# MemoryMapSpring

Веб-приложение для хранения информации о людях и местах их захоронения. Проект разрабатывается в рамках практической работы по Spring.

## О проекте

MemoryMapSpring позволяет хранить сведения о людях, включая имя, фамилию, даты рождения и смерти, описание и информацию о месте захоронения.

Проект реализуется с использованием трёхслойной архитектуры:

- **Слой представления** — контроллеры Spring MVC и JSP-страницы, отвечающие за взаимодействие с пользователем. Данные между слоями передаются через DTO.
- **Слой бизнес-логики** — Spring-сервисы, реализующие операции с данными.
- **Слой доступа к данным** — репозитории Spring Data JPA (Hibernate) и PostgreSQL, используемые для хранения и обработки информации.
